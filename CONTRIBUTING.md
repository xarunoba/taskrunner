# Contributing

## License

By submitting a contribution, you agree that it is licensed under the project's [MIT License](LICENSE). You must have the right to submit the contribution and must preserve any third-party copyright and license notices.

## Code provenance

Submit only code that you wrote or that you are authorized to contribute under terms compatible with the MIT License.

For AI-assisted contributions:

- You remain responsible for the code and its provenance.
- Review generated output before submitting it.
- Do not submit output copied from, or substantially similar to, third-party code with an unknown or incompatible license.
- Disclose material AI assistance in the pull request.
- Identify the source and license of third-party code, documentation, or other material supplied to the model or incorporated into the contribution.

If provenance or licensing is unclear, do not submit the material.
